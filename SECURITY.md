# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in modupy, please report it using GitHub's private security advisory feature:

1. Go to https://github.com/jeansossmeier/modupy
2. Click the **Security** tab
3. Select **Report a vulnerability**

This creates a private advisory that only you and the maintainer can see, allowing for responsible disclosure and a patch before public disclosure.

Do not open a public issue for security vulnerabilities.

## Bug Bounty

There is no bug bounty program. Security fixes are welcomed and credited in the changelog.

## Supported Versions

This is alpha software (Development Status :: 3 - Alpha in pyproject.toml). Only the latest 0.x release line receives security updates. Once v1.0 is released, the support policy will be documented.

To stay current:
- Monitor [CHANGELOG.md](CHANGELOG.md) for release notes
- Watch the repository for new releases
